GAMEVAULT

Términos y condiciones

GameVault es un proyecto académico para descubrir videojuegos. El registro guarda tu nombre, usuario, correo y un hash de tu contraseña en una base de datos local, con fines demostrativos. No incluye inicio de sesión ni servicios de pago.

Utiliza datos de prueba para la presentación. No envíes información sensible. Los datos de videojuegos pertenecen a sus respectivos titulares y son proporcionados por RAWG.

Al registrarte aceptas este uso de tus datos en la instancia local del proyecto. El responsable de esa instancia puede eliminar los registros borrando la base de datos local con el servidor detenido.
